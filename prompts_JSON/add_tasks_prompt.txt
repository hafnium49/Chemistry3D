- **Use of `Sim_Container`:** `Sim_Container1` and `Sim_Container2` should be instances of `Sim_Container`, e.g., `Sim_Bottle1`, not `Bottle1`.

**`add_task` Function:**

- **Type:** Function
- **Description:** Adds a task to the controller manager.
- **Input:**
  - `controller_name` (string): The name of the controller.
  - `param_template` (dict): The parameters for the controller, including an `'action'` key.
- **Output:** None
- **Related Controllers:** `PickMoveController`, `PourController`, `ReturnController`
- **Example Usage:**

```python
controller_manager.add_task('controller', {
    'action': 'pick',
    'picking_position': lambda obs: obs['beaker1']['position'],

controller_manager.add_task('pour_controller', {

    'current_joint_velocities': lambda obs: Franka.get_joint_velocities(),
    'pour_speed': 55 / 180.0 * np.pi
})

controller_manager.add_task('return_controller', {
    'action': 'return',

    'return_position': lambda obs: np.array(obs['beaker1']['Return_Position']),
    'current_joint_positions': lambda obs: Franka.get_joint_positions()
})
```
